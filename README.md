# Shortify - URL Shortener & Analytics Engine

> A high-performance URL shortener like bit.ly, built with Python & FastAPI.

## Features
- ⚡ Shorten any URL to 6-char code
- 📊 Real-time click tracking
- 🔍 Analytics API - /stats/{code}
- 💾 SQLite backend - easy to scale to Postgres

## Tech Stack
Python, FastAPI, SQLite, REST API

## How to Run
pip install fastapi uvicorn
uvicorn main:app --reload
